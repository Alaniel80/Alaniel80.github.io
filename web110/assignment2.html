1. Configure browser extensions and add-ons: I have reviewed my Chrome extensions and realized that I might not be using them to their full potential. The extension I rely on most is AdBlock Plus. It is always enabled and has already blocked over 179,200 items that may have harmed my system or interrupted browsing. My X New Tab Page extension stopped working for some reason, so I replaced it with Live Start Page – Living Wallpapers. With this extension, I was able to customize most viewed pages by groups, set up a clock, a weather widget, and a live wallpaper for the start page. I installed Grammarly, so I no longer need to open the Grammarly home page and copy/paste text for checking. I also installed Volume Master 2.4.0 to test its ability to boost audio volume and enhance voices over the background sounds or music and vice versa. After testing it with different YouTube videos, I found it very helpful. I will continue exploring Chrome Web Store for more options to further customize my browser. 2. Configure browser settings: I went to Chrome settings under Appearance and added Bookmarks, History, Downloads, and Password Manager to the toolbar for quick access, which will save me time instead of going through the menu. Under Privacy and Security - Site settings, I reviewed the permissions websites have and made sure that sites always ask before using the camera and microphone. And while going through the settings, I realized that I have not cleared cache, history, and cookies for a very long time. I usually avoid doing this because keeping them helps access sites faster and allows me to stay logged in without entering passwords. 3. Install multiple web browsers to compare the different programs: My favorite browser is Chrome, and Microsoft Edge is a built-in browser that I keep as a reliable backup. Edge has a great option to split the screen, which allows for better viewing and control when multitasking, especially if there is no second monitor involved. For Chrome, that option is available through extensions, and some of them offer more advanced splitting templates. Chrome has the largest extension library, even though Edge supports the Chrome Web Store in addition to the Microsoft Store. Edge uses less memory with similar search speed to Chrome, which might be better for multitasking. In terms of privacy and security, Edge has stronger built-in privacy controls and tracking prevention, while Chrome’s privacy settings require more manual adjustments. I find the two browsers very similar, so for me it comes down to personal preference.
