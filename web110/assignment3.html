Cite a web page. • Use Special:CiteThisPage to cite a Wikiversity web page. Compare the different citation formats available. Do all formats include the same information? I used Special:CiteThisPage to cite a Wikiversity page Internet Fundamentals/Web Browsers - Special:CiteThisPage/InternetFundamentals/WebBrowsers. The citation formats available for this page share the same basic goal: to provide enough information for a reader to identify and locate the source. Most citations include the page title, publisher or the website, the date and the URL. However, each style organizes this information differently and uses different punctuation, based on the conventions of its academic field. APA places the date after the author, while MLA focuses more on the title and publication details. MHRA and Chicago styles are very similar, and both include an access date, acknowledging that online content can change over time. Bluebook style uses the phrase “last visited” instead of “accessed”. CBE/CSE has a more technical format and identifies the source as an Internet resource. BibTeX differs from the narrative citation styles because it stores information in a structured format designed for machine reading rather than human punctuation rules.
